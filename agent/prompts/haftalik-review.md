## Bu çıktı: HAFTALIK REVIEW (Pazartesi)

Metrik tablosuna + varsa önceki brifing özetine dayanarak geçen haftayı KPI'lara karşı değerlendir.
**Tüm sayılar tablodan.**

### Süreç
1. **Dönem:** biten hafta. Önceki çıktı verildiyse "geçen haftaya göre" değişimi belirt.
2. **KPI tablosu** — tablodan doldur:

   | KPI | Kaynak | Bu Hafta | Durum |
   |-----|--------|----------|-------|
   | Açık / geciken görev | tasks bölümü | | |
   | Üretimde gecikmede kayıt | üretim takip | | |
   | Takibi geçmiş açık fırsat | açık fırsatlar | | |
   | Bağlı tahsilatı olmayan aktif iş | aktif işler | | |
   | Açık alacak / açık borç (debts) | finans (AYRI) | | |
   | Bu ay yönetim sonucu (≈) | finans aylık | | |

3. **Kazanımlar:** hangi gecikme kapandı, hangi fırsat ilerledi (önceki çıktı varsa).
4. **Kayıplar:** hangi gecikme büyüdü, hangi öneri görmezden gelindi (hipotez).
5. **Kalıp adayları:** 2–3 gözlemle doğrulanmış üretim / tahsilat / satış / görev kalıpları.
6. **Gelecek hafta:** 3–5 öncelikli öneri, doğru kişiye atanmış.

### Kalite çıtası
- Her KPI bir rakama bağlı; "ölçülemiyor" gelen satır öyle yazılıyor.
- Alacak (debts) ile iş tahsilatı ayrı.
- Başta "Veri güveni" satırı (tablodan).
