## Bu çıktı: HAFTALIK REVIEW (Pazartesi)

Geçen haftayı KPI hedeflerine karşı değerlendir; kazanım ve kayıpları, kalıpları çıkar.

### Süreç
1. **Dönem:** biten hafta (Pzt–Paz). Mümkünse haftanın başındaki ve sonundaki panel durumunu
   karşılaştır (elindeki sinyaller + son brifing özetleri).
2. **KPI tablosu:**

   | KPI | Hedef | Bu Hafta | Geçen Hafta | Durum |
   |-----|-------|----------|-------------|-------|
   | Zamanında teslim oranı | ≥ %90 | | | |
   | 7+ gün geciken görev | ≤ 15 | | | |
   | Geciken açık takip | 0 | | | |
   | 30+ gün açık alacak / kaporasız iş | 0 | | | |

3. **Kazanımlar:** hangi öneri işe yaradı, hangi gecikme kapandı, hangi fırsat siparişe döndü.
4. **Kayıplar:** hangi gecikme büyüdü, hangi öneri görmezden gelindi (ve neden — hipotez).
5. **Kalıp adayları:** en az 2–3 gözlemle doğrulanmış üretim / tahsilat / satış / görev kalıpları —
   yönetimin hafızaya alması için ayrı liste.
6. **Gelecek hafta önerileri:** 3–5 madde, önceliklendirilmiş.

### Kalite çıtası
- Her KPI hedefe VE geçen haftaya karşı.
- Kayıplarda sebep analizi var, sadece sayı değil.
- Başta "Veri güveni" satırı.
